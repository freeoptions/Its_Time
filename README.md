# 到点啦

一款面向小米 13 / MIUI 的轻量提醒工具。默认按明亮冷调界面设计，提醒内容在到点后进入系统任务栏；用户将通知划掉后，重复任务会排到下一次，单次任务会标记为已完成。

## 已实现

- 临时提醒：到点提醒一次，完成后不再出现。
- 每天重复：例如每天 18:00 提醒。
- 工作日重复：按周一至周五计算，自动跳过周六、周日。
- 持续时间：通知可设置保留 1–24 小时，默认 6 小时。
- 通知滑除完成：通过通知 `deleteIntent` 识别用户划掉动作。
- 精确闹钟：获得“闹钟和提醒”权限后使用 `setAlarmClock`，无权限时降级到待机唤醒闹钟。
- 系统闹钟唤醒：不依赖应用进程常驻后台；首页会显示精确闹钟权限状态。
- 自动对账恢复：应用回到前台、设备重启、应用升级、修改时间或时区后都会重新核对并安排提醒。
- 单次提醒固定绝对触发时间：进程重建后不会被错误推迟到下一天；错过后重新打开应用会立即补发。
- Android 13+ 通知权限：第一次保存提醒时请求通知权限。
- 可靠性检查：首页同时检查精确闹钟、通知总开关和提醒通知渠道，异常时直接进入对应系统设置。
- 调度诊断：首页显示最近一次闹钟的提交类型、目标时间和提交时间，并明确区分“系统闹钟触发”“打开 App 后补发”“系统恢复后补发”及通知发布时间。
- 可靠性设置页：首页右上角进入，可自动检查通知权限、提醒渠道和精确闹钟权限，并可直达小米自启动、电量策略设置；自启动、无限制电量和最近任务上锁采用人工确认，避免把系统无法查询的状态误报为已开启。
- 本地诊断日志：滚动保存最近 120 条调度元数据，区分进程启动、界面进入前台、系统闹钟触发、通知发布、打开 App 补发和系统恢复；不记录提醒标题，可一键复制或分享给开发者排查。
- 测试数据：首次启动且没有提醒时自动生成“测试提醒（可修改）”，默认约 5 分钟后触发、仅提醒一次；删除后不会重复生成。

## 说明

“工作日”当前按周一至周五判断。Android / MIUI 没有向普通应用稳定公开的统一法定节假日接口，因此不会把中国法定节假日自动当作休息日；如后续需要，可再接入用户日历或节假日数据源。

## 小米 13 / MIUI 可靠性设置

系统闹钟可以在应用进程被回收后唤醒提醒，但 MIUI 的自启动、电量策略和通知权限仍可能影响显示。首次安装后建议在“设置 → 应用 → 应用管理 → 到点啦”中确认：

- 通知权限已允许；
- “闹钟和提醒”特殊权限已允许；
- 电量使用策略设为“无限制”；
- 如果系统提供“自启动”，允许到点啦自启动；
- 在最近任务中给“到点啦”任务卡上锁，并保留任务卡；
- 不要对到点啦执行“强行停止”，不要划掉已上锁的任务卡，也不要在安全中心清理它的闹钟权限。

上述项目可在应用首页右上角的“提醒可靠性”页面逐项检查。小米未向普通应用开放“自启动”和“最近任务上锁”的可靠读取接口，因此页面会明确标注为人工确认，不会伪装成自动检测结果。

APK 的应用名称和显示名称均为“到点啦”，application id 为 `com.daodianla.app`。正式 Release 构建后执行 `:app:exportReleaseApk`，会在 `app/build/outputs/apk/release/到点啦.apk` 生成指定文件名的 APK。
